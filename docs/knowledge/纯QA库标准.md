# 纯 QA 库标准

契约：`avatar-qa/v1`

纯 QA 与六维知识、产品卡和表达风格完全分开。每条记录包含：

- 标准问，最长 500 字；
- 固定答案，命中后必须原样输出；
- 别名与关键词；
- `public / course / internal` 权限及课程范围；
- 0～6 张图片，按保存顺序输出；
- `draft / approved / published / rejected / archived` 状态。

图片必须使用公网 HTTPS URL，只允许标准 443 端口；禁止账号信息、fragment、localhost、私网或保留地址。`alt_text` 最长 200 字，不能包含 HTML 或控制字符。

运行时先做权限过滤，再对标准问、别名、关键词和固定答案进行高置信匹配。只有唯一且足够明确的最佳结果才会绕过模型；候选接近时视为未命中，继续进入六维知识问答链。旧 V1 QA 不迁移、不展示、不检索。
